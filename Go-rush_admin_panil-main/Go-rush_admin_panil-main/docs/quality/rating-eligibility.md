# Rating Eligibility & Privacy

## Eligibility Rules
- A Rating can ONLY be submitted when the authoritative `RideStatus` is `RIDE_COMPLETED`.
- Cancelled rides are NOT rateable pending Business Rules clarification.

## Mutual Rating Privacy
**Status:** BUSINESS DECISION REQUIRED
It is currently undefined whether a Partner can immediately see a Customer's rating, or if it is delayed to prevent retaliatory ratings. All API responses currently mask the opposing rating until this is resolved.
