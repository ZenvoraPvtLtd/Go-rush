# Consent & Privacy Foundation

## Progressive Consent
GoRush uses progressive profiling and consent:
1. **Terms & Privacy Policy**: Acknowledged during the Phone Authentication step.
2. **Profile Setup**: Only essential information (Full Name) is required. Email is optional.
3. **Location Permission**: Not requested at app startup. It is requested contextually on the Home screen when a ride is initiated or map interaction requires it.

## Future Consent Tracking
The backend architecture will support versioned consent records (e.g., `consentType`, `version`, `acceptedAt`) to remain compliant with data protection regulations.
