# Testing Strategy

## Flutter
- **Unit Tests**: Domain logic, models, state parsers.
- **Provider Tests**: Riverpod state updates and derivations.
- **Widget Tests**: Crucial UI states (App Startup, Design System integrity).

## Backend
- **Unit Tests**: Services and shared utility functions.
- **Controller Tests**: HTTP boundaries and DTO validation.
- **E2E Tests**: Basic request lifecycle and error structures.
