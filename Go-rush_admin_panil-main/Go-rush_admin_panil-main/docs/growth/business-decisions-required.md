# Business Decisions Required Register

The following Growth policies must be explicitly defined by the Business before the Promotion Platform can be utilized for Live Operations:
1. **Maximum Discount Limits:** The absolute maximum monetary value any single coupon can discount.
2. **Referral Reward Values:** The exact amount awarded to Referrer vs Referee, and the conditions required (e.g., must complete 1 ride first).
3. **Refund Logic:** If a Customer cancels a ride paid with a Promo Code, do they get the code back?
4. **Partner Incentive Matrix:** The logic governing "Complete 10 rides, earn $50".
