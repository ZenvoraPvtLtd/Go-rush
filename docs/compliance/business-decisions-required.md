# Business Decisions Required Register

The following Compliance policies must be explicitly defined by the Business before the Onboarding Platform can be utilized for Live Operations:
1. **Cloud Storage Provider:** (e.g., AWS S3, GCP Cloud Storage) for hosting images.
2. **KYC / OCR Provider:** To validate Aadhaar, PAN, DL, and RC.
3. **Legal Document Matrix:** Explicit list of which documents are MANDATORY vs OPTIONAL for each operating City/Country.
4. **Data Retention Policy:** How long we must keep a rejected Driver's ID card before deleting it for privacy compliance.
