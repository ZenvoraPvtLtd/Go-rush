## 3. System Resilience & Chaos Architecture
The system is designed for high availability:
- **Stateless APIs**: NestJS pods can be killed and restarted without data loss.
- **Idempotent Workers**: BullMQ queues ensure that a crashed worker will safely retry the job upon TTL expiration.
- **Database Primacy**: Redis is used purely as a transient cache and geohash index; all canonical financial and ride state is durable in PostgreSQL.
